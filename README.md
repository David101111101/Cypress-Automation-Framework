# Cypress Automation Framework (Advanced Techniques)

A Cypress-based automation framework showcasing advanced testing techniques across:
- Backend/API test automation with Postman & Devtools, APIs GraphQL con PokeAPI, CRUD with NoSQL con MongoDB, SQL & MySQL
- Dockerized execution
- Node.js tasks & utilities
- Cookies & Local Storage
- Plugins
- Retries & flake control
- Error interception & network stubbing
- Page Object Model (POM)
- Custom Commands
- Environment variables
- Multiple tabs interaction (workarounds)
- Fixtures & test data management
- Parallel testing
- Video reporting & artifacts
- Json Server
- Headers 

## Tech Stack
- **Cypress** (E2E + component-style patterns)
- **Node.js** (tasks, utilities, local tooling)
- **Docker** (repeatable execution environment)
- Optional: reporters (JUnit/Mochawesome), parallel runner, grep/tag utilities


## Prerequisites

- Node.js LTS

-  npm / pnpm / yarn

- (Optional) Docker Desktop

## To open Cypress dashboard use:
npx cypress open
